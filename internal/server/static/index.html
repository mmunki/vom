How VOM runs Android

1
Download

VOM reads Google's system-image repository and fetches the exact package you pick. The SHA-1 is checked before anything is unpacked.

2
Create

A standard AVD is written with the image path, ABI, RAM, screen size and Play Store flag, so the emulator (and Android Studio) see a normal device.

3
Boot

VOM launches Google's emulator with hardware acceleration. A window opens on the desktop; headless mode is available for CI.

Running a full Android system inside an unrooted Android app is not possible without hypervisor or root access. VOM therefore runs the real Google emulator on a desktop host; the same interface works in a phone browser on your network.

Source & licensing

Images are fetched from dl.google.com/android/repository. AOSP images are Android Open Source Project builds; Google APIs and Google Play images are subject to Google's Android SDK license. VOM itself is Apache-2.0 and keeps no copy of Google's SDK in its source tree.
